# InkNote releases

Signed Android installation packages for InkNote.

## Install

1. Open the latest release.
2. Download the `InkNote-*-release.apk` file.
3. Open it on your Android device and allow installation from the browser or file manager when prompted.

Android may warn that the app came from outside Google Play. Verify the SHA-256 checksum shown in the release before installing.

## Updates

New versions are published as GitHub Releases. The public release feed can also be followed with Obtainium.

The application source is maintained separately in a private repository.
